# L' Hopital's'Rule

> Suppose that $f(a) = g(a) = 0$ and both are differentiable in an open interval $I$ containing $a$ and that $g'(x) \ne 0$ on $I$ if $x \ne a$. Then,
> $$\lim_{x \to c} \frac{f(x)}{g(x)} = \lim_{x \to c} \frac{f'(x)}{g'(x)}$$
> Assuming that the right side of this equation exists.

## Usage

1. Can only be implied if the fraction resolves to $\frac{\infty}{\infty}$ and $\frac{0}{0}$.
2. Any other indeterminate form should ideally be converted to one of the above.
3. Check whether the current expression can be simplified so the limit can be solved. If not, apply rule again.
