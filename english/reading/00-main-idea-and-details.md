# Main Idea

> It is a statement which describes the whole passage in a single sentence.

Can be:
- Stated
- Implied (must be infered)

## Stated Main Idea

> Written directly in the passage.

1. Select a candidate sentence.
2. Check whether details point back to it.

-> Model: `CSCD`
Candidate Sentence, Check Details

## Implied Main Idea

> Not explicitly mentioned.

1. Find the topic.
2. Extract details.
3. Figure out the message of the passage.
4. Restate the idea in a single sentence.

-> Model: `TDMR`
Topic, Details, Message, Restate

> [!info] Topic vs Main Idea vs Supporting Details
> 1. **Topic:**
>    - Name of the passage or subject.
>    - Can be a word or phrase.
> 
> 2. **Main Idea:**
>    - A single statement describing the passage.
>    - Must be a declarative sentence (not a question).
> 
> 3. **Supporting Details:**
>    - Details, facts, and information that support the main idea.

> [!tip]
> `furthermore` and `moreover` are often signals for major details.


# Supporting Details

## Major Details

> Directly support, prove or explain the main idea.

+ Significant information is provided.
+ Acts as core evidence

## Minor Details

> Support, explain or add specific context to major details.

+ Information is minimal
+ Has small to no effect if removed.
